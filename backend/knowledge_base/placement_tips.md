# Placement Preparation Guide for CSE Freshers (India)

## Timeline: 6 Months to Placement Ready

### Month 1-2: Foundation
- Pick one language (Python or Java) and master it
- Complete DSA basics: arrays, strings, recursion
- Learn Git + GitHub basics
- Build your first project (simple CRUD app)

### Month 3-4: Intermediate
- DSA: Trees, Graphs, DP basics
- Learn a web framework (FastAPI or React)
- Start LeetCode — 2 problems daily
- Build project 2 (something with an API)

### Month 5-6: Interview Prep
- Mock interviews weekly
- Resume polish
- LeetCode contests
- Apply broadly — quantity + quality

---

## Resume Tips for Freshers

### Structure (1 page only)
1. Name + Contact + LinkedIn + GitHub (no photo)
2. Summary (2 lines about your goal)
3. Skills (languages, frameworks, tools)
4. Projects (2-3, most important section)
5. Education
6. Certifications (optional)

### Projects Section — Most Important
Each project should have:
- Name + 1-line description
- Tech stack used
- Live link + GitHub link
- 2-3 bullet points of what you built

### ATS Keywords to Include
Python, JavaScript, React, FastAPI, Node.js, SQL, Git, REST API, Docker, Machine Learning, LangChain, AWS, Problem-solving, Data Structures, Algorithms

### Common Resume Mistakes
- Too many pages (keep to 1 page for freshers)
- No live links or GitHub
- Listing skills without proof (projects)
- Generic objective statements
- Spelling mistakes
- Using fancy templates that confuse ATS

## Technical Interview Rounds (typical)

### Round 1: Online Assessment (OA)
- Platform: HackerRank, CodeSignal, Mettl
- 2-3 DSA problems in 90 minutes
- May include MCQs (OS, DBMS, networking)
- Tip: Practice on the same platform before interview

### Round 2: Technical Interview 1
- DSA problems (Easy to Medium)
- Explain your approach before coding
- Time + space complexity must be discussed
- May ask about your projects

### Round 3: Technical Interview 2
- System design (for product companies)
- Core CS subjects: OS, DBMS, CN
- Language-specific questions
- Deep dive into your resume projects

### Round 4: HR Round
- Why this company?
- Tell me about yourself
- Where do you see yourself in 5 years?
- Salary negotiation

## Core CS Subjects to Revise

### Operating Systems
- Process vs Thread
- Deadlock (conditions, prevention)
- Memory management (paging, segmentation)
- CPU scheduling algorithms
- Virtual memory + page faults

### DBMS
- ACID properties
- Normalization (1NF, 2NF, 3NF, BCNF)
- SQL: JOINs, GROUP BY, Window Functions
- Indexing (B-tree, Hash)
- Transactions and concurrency

### Computer Networks
- OSI model (7 layers)
- TCP vs UDP
- HTTP/HTTPS, DNS, DHCP
- REST vs GraphQL
- What happens when you type google.com

### OOP Concepts
- 4 pillars: Encapsulation, Inheritance, Polymorphism, Abstraction
- SOLID principles
- Design patterns (Singleton, Factory, Observer)

## Top Companies for Freshers (2024-25)

### Mass Recruiters (easier to crack)
TCS, Infosys, Wipro, HCL, Cognizant, Capgemini, Tech Mahindra
- Salary: 3.5–5 LPA
- Selection: Online test + HR round
- Tip: Focus on aptitude + communication

### Mid-Tier Product Companies (worth targeting)
Zoho, Freshworks, Chargebee, Postman, BrowserStack, Razorpay, Clevertap
- Salary: 6–14 LPA
- Selection: Coding test + 2-3 technical rounds
- Tip: Strong projects + medium LeetCode

### Unicorns / Top Startups
Zomato, Swiggy, Meesho, CRED, PhonePe, Groww, Zepto, slice
- Salary: 12–25 LPA
- Selection: Hard DSA + system design
- Tip: 200+ LeetCode + strong system design basics

### FAANG+ (dream companies)
Google, Microsoft, Amazon, Meta, Apple, Adobe, Atlassian
- Salary: 30–80 LPA
- Selection: 5-6 rounds, hard DSA, system design
- Tip: 1+ year of dedicated prep, 300+ LeetCode

## LinkedIn Optimization Tips
- Professional headshot (mandatory)
- Headline: "CSE 2024 | Python | React | AI Enthusiast | Open to Opportunities"
- About section: 3-4 lines about your skills and what you're looking for
- Add all projects with links
- Connect with 500+ people in tech
- Post 1-2 times a week about what you're learning
- Engage with content from target companies
- Get 3+ recommendations from professors or seniors
