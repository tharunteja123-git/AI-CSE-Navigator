# CSE Career Paths Guide for Indian Students

## 1. AI / ML Engineer
**Role:** Build intelligent systems using machine learning, deep learning, and LLMs.
**Average Salary:** 8–25 LPA (fresher: 6–10 LPA)
**Top Companies:** Google, Microsoft, OpenAI, Flipkart, Swiggy, Meesho, upGrad, CRED

### Required Skills
- Python (NumPy, Pandas, Scikit-learn)
- Deep Learning: TensorFlow or PyTorch
- LLMs: LangChain, HuggingFace, Gemini/OpenAI API
- RAG (Retrieval-Augmented Generation)
- MLOps: MLflow, Docker, FastAPI deployment
- Mathematics: Linear Algebra, Statistics, Probability

### Roadmap (6 months for fresher)
Month 1: Python + Math foundations
Month 2: Classical ML with scikit-learn
Month 3: Deep Learning (PyTorch)
Month 4: NLP + Transformers + LLMs
Month 5: Build 3 AI projects + deploy
Month 6: DSA + interview prep + apply

### Top Certifications
- DeepLearning.AI TensorFlow Developer (Coursera)
- Google ML Crash Course (free)
- HuggingFace NLP Course (free)
- AWS Machine Learning Specialty

---

## 2. Full Stack Developer
**Role:** Build end-to-end web applications — frontend + backend + database.
**Average Salary:** 5–18 LPA (fresher: 4–8 LPA)
**Top Companies:** Razorpay, Zepto, Zomato, Paytm, Myntra, Groww, startups

### Required Skills
Frontend: React.js, Tailwind CSS, TypeScript
Backend: Node.js + Express OR Python + FastAPI
Database: PostgreSQL, MongoDB, Redis
DevOps: Docker, basic CI/CD, Nginx
Testing: Jest, Pytest

### Roadmap
Month 1: HTML, CSS, JavaScript ES6+
Month 2: React + Tailwind
Month 3: Backend (FastAPI or Node.js)
Month 4: Databases + REST API design
Month 5: Full stack project (deploy on Render/Vercel)
Month 6: DSA + system design basics

---

## 3. Backend Developer
**Role:** Design and build scalable server-side systems, APIs, and databases.
**Average Salary:** 6–20 LPA
**Top Companies:** PhonePe, Juspay, Dunzo, Meesho, BrowserStack

### Required Skills
- Python (FastAPI/Django) or Java (Spring Boot) or Go
- Database design: PostgreSQL, MySQL
- Caching: Redis
- Message queues: RabbitMQ, Kafka basics
- Docker + Kubernetes basics
- REST API + gRPC design

---

## 4. DevOps Engineer
**Role:** Automate infrastructure, deployments, CI/CD pipelines, and monitoring.
**Average Salary:** 7–22 LPA
**Top Companies:** Accenture, Infosys (cloud teams), Freshworks, Druva

### Required Skills
- Linux administration
- Docker + Kubernetes
- AWS / GCP / Azure (at least one)
- CI/CD: GitHub Actions, Jenkins
- Infrastructure as Code: Terraform
- Monitoring: Prometheus, Grafana

---

## 5. Data Scientist
**Role:** Analyze data, build statistical models, and generate business insights.
**Average Salary:** 6–20 LPA
**Top Companies:** Amazon, Walmart Labs, Mu Sigma, Fractal Analytics

### Required Skills
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL (complex queries, window functions)
- Machine Learning (scikit-learn)
- Statistics and A/B testing
- Tableau or Power BI
- Spark basics for big data

---

## Placement Statistics India 2024
- Average package for tier-1 colleges: 8–15 LPA
- Average package for tier-2 colleges: 4–8 LPA
- Service companies (TCS, Infosys, Wipro): 3.5–5 LPA
- Product startups (funded): 8–20 LPA
- FAANG India: 30–80 LPA

## Top Skills Recruiters Look For in 2024-25
1. Python or JavaScript proficiency
2. At least one framework (React, FastAPI, Spring)
3. SQL and database knowledge
4. DSA (LeetCode Medium level for product companies)
5. Git and version control
6. At least 2-3 real projects with live deployment
7. Communication and problem-solving in interviews
